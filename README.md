## Cassa

Public version of a website created with [GokaiInfinity](https://github.com/GokaiInfinity) for a school project in December 2023 - January 2024.

GokaiInfinity did most of the front end work, while I did most of the back end.

The website is created to manage deliveries of various factory and industrial parts. Whatsapp is integrated in order to chat with the delivery person.
